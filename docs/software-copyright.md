## 2. 办理入口与流程

入口：中国版权保护中心 `https://www.ccopyright.com.cn/`（软件登记业务已线上化）。

1. **注册账号 + 实名认证**：个人选「个人」主体，填姓名、身份证号、手机号，按提示上传身份证正反面；实名通过后方可提交申请。
2. **我要申请 → 软件著作权登记申请（R11）**：按 §3 逐项填写。
3. **上传材料**：源程序 PDF、文档 PDF、身份证明；按系统提示完成申请表确认页的签名（个人为手写签名，在线签名或下载签字后扫描上传）。
4. **提交 → 等待受理与审查**：若被要求补正，系统内会给出补正通知，按通知在期限内补交。
5. **下证**：审查通过后下载电子证书（现已为电子证）。软件著作权登记相关费用已停征，官方渠道不收取登记申请费与证书费；整个周期通常为数十个工作日，**具体以官网公示为准**。
6. **回填应用后台**：取得证书编号与证书文件后，在腾讯开放平台对应应用上传资质。

> 页面字段名称与材料格式要求以官网当前页面为准；本文件只提供填写内容与材料。

### 2.1 费用（现行免费，历史标准供参考）

**现在：官方 0 元。** 依据财税〔2017〕20 号《关于清理规范一批行政事业性收费有关政策的通知》，自 **2017 年 4 月 1 日**起停征「计算机软件著作权登记费」；中国版权保护中心同步发布《关于停征软件著作权登记缴费有关事项的通告》，停征范围包括：

1. 软件著作权登记申请费（含申请例外交存手续费）
2. 软件著作权登记证书费
3. 软件著作权合同登记费
4. 变更或补充登记费
5. 软件源程序封存保管费
6. 查询费

**停征前的标准**（1992 年《计算机软件著作权登记收费项目和标准》，国家版权局公布；个别项目后期有调整，中心公示页面另载证书费 10 元/件，以当年公示为准）：

| 项目 | 原标准 |
|---|---|
| 软件著作权登记申请费 | 250 元/件次（仅限程序及一种文档；每增加一种文档增收 80 元） |
| 软件著作权登记证书费 | 50 元/件 |
| 变更或补充登记费 | 150 元/件次 |
| 异议请求费 / 复申请求费 | 150 元/件次 |
| 软件源程序封存保管费 | 100 页内 120 元，超过 100 页每增加 1 页增收 2 元 |
| 请求延期处理费 | 第一次 100 元/件次，第二次 200 元/件次 |
| 查询费 | 题录库近五年信息每题 50 元（超过 100 条每条加收 0.15 元）等 |

因此当年「自己办一件软著」的普遍成本是 **申请费 250 + 证书费 50 ≈ 300 元/件**（不含代办服务费与加急费）。

**现在仍可能产生费用的地方**：代办/代理机构的服务费（市场价几百至数千元不等）、所谓「加急」类第三方服务（非官方收费项目）、以及若选择纸质证书邮寄可能产生的邮寄费用。这些都不是登记费本身，官方线上申请与下载电子证书不收费。
