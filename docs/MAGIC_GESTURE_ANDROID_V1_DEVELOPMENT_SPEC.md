# 魔法手势 Android V1.0 开发规格

版本：V2.2 落地稿  
整理日期：2026-10-01  
适用工程：`MagicGesture-v0.9`

## 1. 产品目标

V1.0 是用户主动开启、使用前置摄像头在其他 App 上方运行的 Android 隔空手势工具。识别、映射、权限判断和系统动作必须解耦；无障碍服务只承担用户主动触发的点击、滑动、全局动作及截图，不读取第三方页面内容。

发布底线：权限用途透明、控制可随时停止、动作结果可反馈、失败不伪装成功、各手势可独立关闭、后台运行状态可见。

## 2. 冻结交互规则

### 2.1 全局动作冷却

- 离散动作执行成功后进入 `2000ms` 全局动作冷却。
- 冷却用于阻止其他离散动作，不是单手势防抖，也不是识别保持时间。
- G01 光标属于连续控制，冷却期间仍可移动。
- G02 点击成功后锁住其他离散动作 2 秒，但不冻结光标。
- 动作未被无障碍服务接受或执行失败时，不启动冷却。
- 连续音量控制（G31/G32 两指保持）在会话中采用独立步进限速；会话结束后再启动全局冷却。

### 2.2 释放后再触发

静态/HOLD 手势触发一次后必须离开该姿势，重新进入才允许下一次触发。冷却期结束本身不能把持续保持的姿势变成新动作（冷却时长用户可配置，0.6–4 秒，默认 1.5 秒）。动态手势和组合手势也必须经过其 `WAIT_RELEASE` 状态，避免回程触发反向动作。

### 2.3 执行链路

```text
Camera frame -> Hand Landmarker -> Gesture detector/state machine
-> GestureEvent -> Mapping -> Feature gate -> GlobalCooldownManager
-> Action executor -> success callback -> 2s global cooldown
```

检测器可保留短时稳定、保持和本地 Repeat Guard，但不得自行把它解释为全局动作冷却。

## 4. Free / Pro 与映射边界

V1 先建立 `Gesture -> Mapping -> FeatureGate -> Action` 边界，不在识别器中写死商业权限。免费版至少保留核心光标、点击和基础方向动作；Pro 手势、App 独立映射、场景模式和自定义动作属于配置层能力。未接入订阅校验前，不展示可购买或已解锁承诺。

## 5. 页面与系统能力

- 首次启动向导：相机、悬浮窗、无障碍、通知/前台服务用途逐项披露。
- 运行状态中心：相机、模型、无障碍、悬浮窗、当前控制状态和可恢复错误。
- 手势中心：显示开关、说明、练习入口、可用状态；待开发手势不可伪装成可用。
- 手势详情/校准：保持时间、动作说明、识别反馈和独立开关。
- 悬浮球：启动中/运行中/错误/冷却状态同步；点击返回 App，可拖动贴边。
- 诊断模式：本地显示识别结果与关键阈值，不上传摄像头画面。

## 6. 当前实现审计

已具备：前置摄像头前台服务、MediaPipe Hand Landmarker、无障碍点击/滑动/全局动作/截图、悬浮光标与状态球、三档灵敏度、左右反转、识别反馈、八组功能开关、G01-G13 中的大部分基础识别链路。

本次 P0 已调整：

- 新增独立 `GlobalCooldownManager`，统一 2 秒全局动作冷却。
- 冷却从识别器中移出，只在动作成功回调后启动。
- 光标和识别反馈加入冷却白名单。
- 保留各检测器原有锁存/`WAIT_RELEASE`，冷却结束不再重置姿势状态。
- 无障碍动作增加成功/失败回调，失败不进入冷却。

尚未完成：Free/Pro 真正校验、完整首次权限向导、正式诊断页、自动化真机验收。G23 已改为伸出小指切换媒体静音并完成代码链路；G18/G19 连续画圈音量已移除。

### 已开发待验收：G21 多 App 收藏

G21 已调整为 `OK → 当前前台 App 的收藏动作`：

- 支持同时配置多个 App，首版不设置固定槽位和业务数量上限。
- 以应用包名区分收藏配置，不读取页面文字或控件内容。
- 每个 App 独立保存竖屏/横屏收藏坐标和启用状态。
- 当前 App 未配置时不执行点击，并提示先完成收藏位置校准。
- App 卸载或收藏按钮位置变化时允许重新关联、重新校准或删除配置。
- 收藏点击注入成功后进入用户当前设置的全局动作冷却；持续保持 OK 不得重复收藏。
- 原页面悬浮标定与校准页配置管理已经接入，当前等待真机验收。

## 7. 开发顺序

1. P0：全局冷却、成功回调、释放复位、G01 白名单（本次完成代码基座）。
2. P1：建立 Gesture Code、Mapping、Action、FeatureGate，迁移 G01-G13（已完成）。
3. P2：实现 G20/G21/G22（代码链路已完成），继续补静态姿势互斥真机数据集与阈值校准。
4. P3：G14-G19、G23 与配置 UI 代码链路已完成；继续进行真机阈值与交互验收。
5. 发布阶段：权限与隐私文案、崩溃/耗电/机型兼容测试、签名 AAB、商店素材与审核说明。

## 8. 验收标准

- 任一离散动作成功后 2 秒内，其他离散动作不执行，但光标持续移动。
- 动作失败不显示成功反馈，也不进入冷却。
- 持续保持 V 字、比心等静态姿势，跨过冷却期仍不重复执行；释放后重新做才可执行。
- 动态手势一次去程只触发一次，回程不反向触发。
- 每个已上线手势均可独立关闭，关闭后不参与识别。
- 停止服务后摄像头、模型、光标和悬浮层全部释放。
- Debug 单元测试和 APK 构建通过；至少在 Android 12、14、15/16 真机完成后台 10 分钟、来电/锁屏/相机抢占和权限撤销测试。
