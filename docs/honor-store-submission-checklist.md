## 5. 权限与敏感能力

需如实申报（荣耀 MagicOS 对无障碍/悬浮窗的审查口径与华为接近，但以后台实际要求为准）：

| 能力 | 说明口径 |
|---|---|
| 相机 | 复用 `docs/huawei-permission-statement.md` §3：仅用户主动启动后使用前置摄像头本机识别，自拍时保存 |
| 悬浮窗 | 复用 §2：光标、状态点、反馈、倒计时、标定面板 |
| 无障碍 | 复用 §1：手势转换为系统操作，核心功能，`canRetrieveWindowContent=false`，不读取窗口内容与页面文字，可随时关闭 |
| 前台服务 | 复用 §3：常驻通知可见、可一键停止 |

华为侧的通过经验可复用：无障碍被归入「专项敏感权限声明」表单时，勾选语义最接近的一项（华为选的是「用于用户创建自动化任务」），并在审核备注里澄清**不涉及短信与通话场景**、附演示视频。若荣耀后台有同类强制必选项，按同样处理并记录到本文。

**优势**：荣耀是真机（ALP-AN00）所在渠道，授权引导与「保持授权不丢失」方案做过真机实测，授权引导文案无需返工。

## 6. 提交顺序（账号已就绪，从这一步开始）

1. 登录荣耀开发者服务平台，确认实名主体与备案主体一致
2. 创建应用，占用包名 `com.magicgesture.app`
3. 上传 `app-release.apk`（1.0.0/10，56,975,586 字节），跑荣耀的安全/合规自动检测，按结果整改
4. 按后台当页规格上传图标与**按新 UI 重截的截图**
5. 填文案、分级、个人信息与权限说明（附演示视频）
6. 填备案号（主办单位侯兴章）→ 提交审核
7. 提交后回填本文状态与提交时间、版本号
