## 5. 权限与敏感能力

需如实申报（荣耀 MagicOS 对无障碍/悬浮窗的审查口径与华为接近，但以后台实际要求为准）：

| 能力 | 说明口径 |
|---|---|
| 相机 | 复用 `docs/huawei-permission-statement.md` §3：仅用户主动启动后使用前置摄像头本机识别，自拍时保存 |
| 悬浮窗 | 复用 §2：光标、状态点、反馈、倒计时、标定面板 |
| 无障碍 | 复用 §1：手势转换为系统操作，核心功能，`canRetrieveWindowContent=false`，不读取窗口内容与页面文字，可随时关闭 |
| 前台服务 | 复用 §3：常驻通知可见、可一键停止 |

**优势**：荣耀是真机（ALP-AN00）所在渠道，「保持授权不丢失」的荣耀/华为方案本来就做过真机实测（提交 95864c6 系列），授权引导文案无需返工。

## 6. 提交顺序

1. 注册荣耀账号 → 个人实名认证（与备案主体一致）
2. 创建应用，占用包名 `com.magicgesture.app`
3. 上传 APK，跑荣耀的安全/合规自动检测，按结果整改
4. 按后台当页规格上传图标与截图
5. 填文案、分级、个人信息与权限说明（附演示视频）
6. 填备案号 → 提交审核

## 7. 上架后

- 用 ALP-AN00 从荣耀应用市场**搜索并下载安装一次**，验证商店包的安装、授权引导、手势识别全链路（这是本渠道独有的优势，必须做）
- 核对详情页图标、截图、介绍与备案号展示
- 结果回填本文与 `docs/IDE_DEVELOPMENT_HANDOFF.md`
