# 魔法手势：手势与动作映射检查清单

更新日期：2026-10-01  
适用工程：`MagicGesture-v0.9`  
代码基线：当前工作区中的 `GestureEngine.kt`、`GestureArchitecture.kt`、`MainActivity.kt`

## 1. 使用说明

- 本文列出的是代码内置的**出厂默认动作**，不是某台手机 SharedPreferences 中可能存在的用户换绑结果。
- G01～G33 共 33 个编号；当前有真实识别链路 30 个，尚未实现 3 个。
- **维护约定**：任何新手势落地、默认动作或开关变更时，必须同步更新本文档对应条目。
- 除 G01 外，已有真实识别链路的手势都允许在“手势练习与校准 → 手势动作映射”中换绑动作。
- 除 G01 连续光标外，动作执行成功后进入 2 秒全局冷却；当前实现会在冷却期间停止全部手势检测并清空未完成状态。
- 表格中的“保持约 0.6 秒”是当前静态手势的一般触发时间；G11、G13、G26 等特殊状态机以各自说明为准。

## 6. 当前冷却规则

- G01 连续移动光标：无冷却。
- 其余已实现手势：只有动作成功后才进入 2 秒全局冷却。
- 动作提交失败或执行失败：不进入冷却。
- 冷却期间：摄像头帧不进入手势识别管线；光标、反馈、保持计时、挥动轨迹和序列状态均停止。
- 冷却开始时会清空未完成的手势状态；冷却结束后从全新状态重新识别。
