# 魔法手势：手势与动作映射对照表

更新日期：2026-10-02  
适用工程：`MagicGesture-v0.9`  
代码基线：`GestureArchitecture.kt`（默认映射、动作目录、功能开关）、`GestureEngine.kt`（识别链路）、`GesturePreferences.kt`（开关与冷却配置）、`FavoriteButtonController.kt`（收藏标定）

## 1. 阅读约定

- 本表记录代码内置的**出厂默认映射**，不含用户换绑结果；换绑结果保存在本机偏好中，可在“手势练习与校准 → 手势动作映射”查看。
- 编号共 G01–G34；其中 33 个具备真实识别链路，G23 仅枚举占位。
- 除 G01 固定为光标外，其余具备链路的编号均可换绑动作；G23 不可换绑、无默认动作。
- 静态手势一般保持约 0.6 秒触发；G11（2 秒）、G22（1.5 秒）、G25（2 秒）以及序列类 G13、G16–G19、轨迹类 G26 以表格中的节奏说明为准。
- 首页卡片的紫色动作名称实时读取当前映射；灰色说明只描述姿势与节奏，不写死默认动作结果。

## 5. 冷却与功能开关

- **G01 连续光标**：无冷却。
- **其余手势**：仅动作成功后进入全局冷却，默认 1.5 秒；可在“手势练习与校准 → 手势冷却时长”拖动配置为 0.6–4 秒，运行中的控制服务即时生效，冷却中的锁不会被中途变更打断。
- **失败不冷却**：动作提交失败或执行失败直接结束，不进入冷却。
- **冷却期间**：摄像头帧不进入识别管线，光标、反馈、保持计时、挥动轨迹与序列状态全部停止并清空，冷却结束后从全新状态重新识别。
- **开关对应关系**：G03/G04 共用 `index_vertical_scroll`；G05/G06 共用 `palm_vertical_scroll`；G29–G33 共用 `two_finger_media`；G16–G19 分别对应 `open_app_1`–`open_app_4`；其余编号各自独立开关。
