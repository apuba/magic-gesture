## 1. 无障碍服务用途说明（核心，可直接粘贴）

**申请用途**：本应用使用 Android 无障碍服务（AccessibilityService），将用户**主动做出的隔空手势**转换为系统级操作，包括点击、滑动、页面滚动、返回、返回桌面、打开最近任务、下拉通知栏、屏幕截图与媒体控制（播放/暂停、上一曲、下一曲、音量调节）；并在用户主动做出「截图」或「滚动长截图」手势时，通过已声明的 `canTakeScreenshot` 能力获取屏幕画面，用于生成待保存的图片。

**为什么必须使用无障碍服务**：上述操作需要跨应用执行。Android 系统未提供任何其他公开接口可以在不成为前台应用的情况下完成全局点击、滑动与导航；不使用无障碍服务，本应用的全部手势控制功能都无法实现，即该能力属于**核心功能，非附加功能**。

**使用范围（仅以下场景触发）**：

1. 用户点击「启动手势控制」主动开启后，且识别到已配置手势时才执行动作
2. 执行的动作限于：点击、滑动、滚动、返回、返回桌面、打开最近任务、下拉通知栏、截图、媒体控制
3. 打开指定应用（用户在映射页自行绑定目标应用后才生效）
4. 收藏当前内容（用户先在前台应用中标定收藏按钮位置后生效）

**明确不做的事**：

- 不读取窗口内容，配置中 `canRetrieveWindowContent=false`，不获取页面文字、控件树、输入框内容、密码与聊天内容
- 不读取通知内容与通知栏文字
- 不持续截取屏幕画面：已声明无障碍截图能力（`canTakeScreenshot`），但仅在用户主动做出「截图」或「滚动长截图」手势时获取一次或连续几屏画面，只用于生成待保存的图片，保存后即释放
- 不自主决策，不按页面内容自动点击，不在用户未做手势时执行任何动作
- 不收集、不上传任何数据；无障碍服务仅用于执行动作，不用于采集信息
- 不将无障碍能力用于广告、数据统计、用户画像或任何与手势控制无关的用途

**用户知情与控制**：

- 开启前展示独立披露弹窗，说明用途、本机处理、不读取页面文字、可随时关闭，提供「我已了解并继续」与「暂不开启」两个按钮
- 用户未开启服务时，应用不跳转系统设置、不执行任何动作，并提示需要先完成授权
- 用户可随时在系统设置中关闭服务，也可在应用内点击「停止所有控制」或通知中的「停止」立即结束
- 停止后摄像头、悬浮控件与前台服务同时关闭

**佐证**：已提供完整演示录屏（含首启隐私政策同意门与拒绝路径、披露弹窗、系统授权页面、跨应用点击效果、停止收尾），可证明披露、授权与实际使用过程一致。

## 2. 悬浮窗权限用途说明（可直接粘贴）

**申请用途**：在其他应用上方显示手势交互反馈，属于**核心功能**。

**显示内容与场景**：

1. **手势光标**：伸出食指时显示跟随指尖移动的光标，指示当前操作位置
2. **悬浮状态点**：控制运行时在屏幕角落显示状态点，让用户清楚知道识别正在运行
3. **识别反馈文字**：手势被执行后短暂显示结果提示（如「已点击」「播放/暂停」）
4. **自拍倒计时**：V 手势自拍时显示 3 秒倒计时数字
5. **收藏位置标定面板**：用户标定收藏按钮位置时显示的可交互面板

**约束**：

- 悬浮窗仅在用户主动启动手势控制后显示，停止控制后立即消失
- 不遮挡用户操作区域，状态点尺寸最小且可随控制关闭
- 不用于广告、弹窗推广或任何与手势控制无关的展示
- 用户可在系统设置中随时关闭该权限

## 3. 相机、通知与前台服务说明（可直接粘贴）

**相机（核心功能）**：仅在用户主动点击「启动手势控制」后调用前置摄像头，在设备本机识别隔空手势；用户主动做出 V 手势时才拍摄并保存照片到设备相册。识别画面与手部关键点只在设备本机内存中处理，不保存为照片或视频，不上传。未启动控制时不使用摄像头。

**通知（核心功能）**：Android 13 及以上展示前台服务运行状态与「停止」入口，保证摄像头占用对用户始终可见、可控；通知为常驻运行状态通知，不含推广内容。

**前台服务（核心功能）**：用户在其他应用中使用手势控制时维持识别运行，并常驻显示运行状态与停止入口，避免服务被系统静默回收导致用户不知情。

## 4. 隐私与数据处理声明（可直接粘贴）

- **不收集个人信息**：不收集设备标识（IMEI/OAID/MAC）、位置、通讯录、短信、通话记录、账号信息
- **本机处理**：摄像头画面与手部关键点在设备本机内存中处理，日常识别不落盘、不上传
- **无网络能力**：安装包不声明网络权限，不具备向设备外传输数据的能力
- **用户主动触发才保存**：仅自拍、截图、长截图三类操作会保存图片到设备相册 `Pictures/MagicGesture/`
- **本机设置**：手势开关、灵敏度、签到记录保存在应用私有存储，清除数据或卸载后删除
- **无账号与云同步**：无账号、无云端备份，换机不会自动恢复配置
