# 魔法手势 App 完整功能清单

> 整理日期：2026-10-07
> 包名：`com.magicgesture.app`　版本：0.9.0（versionCode 9）
> 数据来源：本机源码 `app/src/main/java/com/magicgesture/app/` 与 `AndroidManifest.xml`，手势与动作以 `GestureArchitecture.kt` 的出厂默认映射为准
> 说明：默认动作可由用户在「手势练习与校准」中改绑；标注「未绑定」的手势出厂不执行任何动作

---

## 1. 产品定位与运行前提

- 前置摄像头识别手部关键点，隔空完成点击、滚动、系统导航、媒体控制、自拍等操作。
- 全部推理在本机完成：构建时已移除 `INTERNET` / `ACCESS_NETWORK_STATE` 权限，无账号、无广告、无云同步、无联网埋点。
- 两项系统授权是使用前提（首页「首次使用设置」引导）：
  1. 悬浮窗权限（显示光标、状态点、识别反馈、收藏标定面板）
  2. 无障碍服务（执行点击、滑动、截图、双击点赞等系统动作）
- 摄像头仅在本 App 的前台服务运行期间开启，停止控制后与悬浮控件一并关闭。

## 2. 页面与服务

| 组件 | 作用 |
|---|---|
| `MainActivity` | 首页：授权引导、启动/停止控制、签到解锁卡片、手势使用指南、使用提示、隐私政策入口 |
| `CalibrationActivity` | 手势练习与校准：灵敏度、镜像、反馈、冷却时长、动作映射、收藏位置、功能开关 |
| `KeepAuthorizationActivity` | 保持授权不丢失：按品牌给出防止授权被回收的设置方案 |
| `PrivacyPolicyActivity` | 隐私政策全文 |
| `ControlAccessibilityService` | 无障碍服务：执行所有系统级动作 |
| `CameraProbeService` | 前台服务（camera 类型）：摄像头采集、手势编排、自拍、悬浮反馈、通知 |

## 3. 首页功能

- **状态条**：显示「准备就绪 / 正在运行 / 已请求停止 / 异常」等运行状态。
- **每日签到解锁卡片**：主动点击签到，解锁进度与「下一次解锁」提示（详见第 7 节）。
- **首次使用设置**：悬浮窗权限、无障碍服务两项卡片式引导，含授权说明与「无障碍不会读取聊天记录/密码」的免责说明。
- **启动手势控制 / 停止所有控制**：启动后开启前台服务与悬浮控件；停止同时关闭摄像头。
- **手势练习与校准 / 保持授权不丢失** 两个入口按钮。
- **手势使用指南**：全部手势卡片，紫色文字实时读取当前绑定动作（换绑后自动更新），并显示当前冷却秒数。
- **使用提示**：光线、距离（约 40–80 厘米）、复位、避免遮挡、灵敏度调整、通知「停止」按钮说明。
- **隐私政策与权限说明** 入口。

补充规则：
- G25 与 G35 在 2026-10-04 互换了默认动作：滚动交给更快的单指枪，通知栏交给需要保持 1 秒、便于中途放弃的双指枪。
- 静态保持类手势（握拳、小指）触发后必须真正松手才能再次触发：姿势消失需持续 800ms，短暂丢手（<600ms）不算松手。
- 双手同时入镜时由主手锁定，切换主手会重置引擎，不会继承上一个手的保持/轨迹状态。

## 6. 手势练习与校准页设置项

- **识别灵敏度**：稳定 / 标准 / 灵敏三档（位移阈值系数 1.28 / 1.0 / 0.78），点击即时生效，运行中无需重启。
- **反转左右方向**：左右滑动与光标方向同步反转。
- **显示识别反馈**：屏幕顶部显示动作名称与 V 字保持进度，即时生效。
- **手势冷却时长**：滑块 0.6–4.0 秒，步进 100ms，默认 1.5 秒；松手即存并热更新。
- **手势动作映射**：每个手势可换成任意动作；选「默认」恢复出厂；选「打开应用」后弹出应用选择器（支持搜索）；修改即时生效。
- **收藏按钮位置**：查看与删除已保存的收藏坐标（按 App + 横竖屏）。
- **手势功能开关**：每个手势一个开关，控制是否参与识别（与解锁权益、动作映射三层互相独立）。
- **练习顺序**：按推荐顺序练习各手势。

## 7. 每日签到解锁

- 初始开放 7 个编号：G01、G02、G05、G06、G24、G11、G13。
- 每天主动签到一次，永久解锁下一个功能包；断签不清零；12 次后 G01–G35 全部拥有。
- 解锁记录只存本机（卸载或清除数据会丢失）；完全离线，Debug 构建可全解锁但不得进入正式包。

| 第 N 次 | 解锁内容 |
|---|---|
| 1 | 握拳播放/暂停 |
| 2 | 两指持续增减音量 |
| 3 | 两指切歌与双击播放暂停 |
| 4 | 小指手势静音开关 |
| 5 | OK 收藏当前内容 |
| 6 | 张掌收指打开常用 App（G16/G17） |
| 7 | 张掌收指打开更多 App（G18/G19） |
| 8 | 莲花指与兰花指 |
| 9 | 并掌左右滚动 |
| 10 | 通知栏与系统导航（G25/G27/G28） |
| 11 | 点赞手势（G12/G20） |
| 12 | 轨迹预留与高级手势（G03/G04/G09/G10/G26/G34/G35） |

未解锁手势：首页卡片显示解锁条件，不能换绑也不能执行，但可以看到姿势说明。

## 8. 收藏（第三方 App）标定流程

1. 在目标 App 做出 OK 手势（或已绑定「收藏当前内容」的手势）。
2. 未标定过 → 悬浮面板询问「现在定义」，停留在当前页面。
3. 拖动准星对准收藏按钮（面板可上移/下移避开遮挡）。
4. 「测试位置」会真实点击一次并提示可能收藏或取消收藏；随后确认是否成功。
5. 保存后提示「再做一次 OK 手势即可收藏」；已保存的应用直接按坐标点击。
6. 坐标按包名 + 横竖屏分别保存为归一化值；可在校准页删除。
7. 排除本 App、系统界面与设置页；从最近任务切换后等待真实前台应用（最多重试 3 次）再点击，不会误用上一个 App 的坐标。

## 9. 反馈、冷却与悬浮窗

- **悬浮状态点**：常驻小圆点，可拖动、自动贴边，点击回到 App；显示运行/冷却/异常状态。
- **识别反馈**：顶部胶囊文字显示动作名称与进度百分比（可关闭）。
- **倒计时**：V 字自拍、握拳等保持类手势显示大号倒计时数字。
- **自拍预览**：保存后短暂显示缩略图，并有倒计时滴答与快门音。
- **冷却期**：动作成功后进入冷却（默认 1.5 秒，可配置 0.6–4 秒），期间暂停全部识别（含光标）；运行中修改冷却不会延长或缩短已开始的冷却。
- **通知**：前台服务通知显示运行状态，附带「停止」按钮，可立即关闭摄像头与全部控制。

## 10. 无障碍服务能力

`ControlAccessibilityService` 提供：光标渲染与隐藏、点击（归一化坐标/像素坐标）、点击光标位置、方向滚动、横向滚动、拖动按下/移动/抬起、系统返回/桌面/最近任务/通知栏、截图、滚动长截图（截帧比对拼接）、锁屏、语音助手、双击点赞、前台应用识别。

事件监听：`typeWindowStateChanged` 与 `typeWindowsChanged`（后者用于部分机型从最近任务恢复任务时不产生窗口状态事件的场景）。

## 11. 权限与隐私

| 权限 | 用途 |
|---|---|
| CAMERA | 前置摄像头手势识别与自拍 |
| FOREGROUND_SERVICE / FOREGROUND_SERVICE_CAMERA | 后台持续识别的前台服务 |
| POST_NOTIFICATIONS | 运行状态通知与「停止」按钮 |
| SYSTEM_ALERT_WINDOW | 光标、状态点、反馈、收藏标定面板 |
| `queries` 声明 | 查询已安装应用（打开应用）与默认音乐 App（播放兜底） |

构建时已 `tools:node="remove"` 移除 `INTERNET` 与 `ACCESS_NETWORK_STATE`。首启需同意隐私政策，不同意则退出且不开启摄像头。

## 12. 保持授权不丢失

- 荣耀 / 华为（真机实测）：上划清理或强行停止会撤销无障碍授权，需加入启动管理白名单。
- 小米 / Redmi（依据公开设置路径整理，未实测）：需自启动、省电策略与后台锁定同时设置。
- 其他品牌：通用建议（允许后台运行与自启动，避免强行停止）。
- Debug 构建支持连点标题 5 次循环预览各品牌方案文案，Release 无该入口。

## 13. 待开发 / 未实现

- **手持物抑制**：控制手拿着物品时不执行手势，仅记录产品方向与验收范围（见解锁需求文档 6.4 节），尚未实现。
- **G03 / G04 / G09 / G10 轨迹手势**：编号与开关保留，当前默认关闭且未绑定动作。
- **OPPO / vivo 品牌保活方案**：待真机确认后补充。
- 单指枪竖向（G25）、C 手势（G27）等阈值标注「待真机校准」。
