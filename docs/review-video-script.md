# 审核演示视频录制脚本（V0.9）

用途：给 Google Play 与国内安卓市场审核使用的一段连续录屏，证明无障碍能力与相机能力是**用户知情、主动开启、全程可见、可随时停止**的。

本脚本是 `docs/APP_STORE_REVIEW_GUIDE.md` §5「显著披露文案与流程」的可执行落地版。脚本中的按钮、弹窗与状态文案必须与实际界面一致，不得为了让视频好看而提前改 App 文案；若 App 文案先改，本文件必须同步。

## 0. 录制前准备

| 准备项 | 要求 |
|---|---|
| 手机状态 | 卸载重装最新 Debug 包，或从设置里清掉本应用数据，让流程从初始状态开始 |
| 桌面 | 先用干净桌面或空白页，**清掉所有通知角标**（尤其短信、微信、电话的未读数字） |
| 第三方 App | 演示跨 App 时只用空白网页、文件管理器或系统设置，**禁止**用短视频、社交、聊天类 App |
| 隐私 | 不得出现人脸、自拍结果、相册内容、聊天记录、账号昵称与头像 |
| 录制参数 | 系统录屏 1080p，开启「显示触摸操作」，关闭前置画中画；不露 position encoder 人脸 |
| 保存 | 原始长视频留档，剪辑时只允许删空白等待段，**不得重排顺序** |

## 1. 分镜表

总时长建议 45–60 秒，节奏以「能看清每一步」为准，宁可慢不要剪。

| 镜号 | 画面 / 操作 | 屏幕上的真实文案 | 字幕（建议） | 时长 |
|---|---|---|---|---|
| 01 | 桌面点击图标冷启动，进入首页 | 顶部状态「● 准备就绪，等待启动」；未完成授权时显示「请先完成以上两项设置，再启动手势控制。」 | 魔法手势：隔空操控手机 | 4s |
| 02 | 点击「去开启无障碍服务」→ 停下阅读弹窗，完整展示披露正文 | 标题「开启无障碍服务前请确认」；正文含用途、本机摄像头处理、不读取聊天内容密码与页面文字、可随时在系统设置中关闭 | 开启前会先说明用途，不会直接跳转系统设置 | 6s |
| 03 | 点击「暂不开启」 | 弹窗关闭，停留在首页，状态栏无变化，没有进入任何系统页面 | 选择「暂不开启」不会被当作同意，也不会跳转 | 4s |
| 04 | 再次点击「去开启无障碍服务」→ 点击「我已了解并继续」 | 跳转系统无障碍设置页 | 确认后由用户本人进入系统无障碍页面开启 | 5s |
| 05 | 在系统页「已下载的应用 / 已安装的服务」中找到魔法手势并打开开关 | 系统页面原文保留，不做遮挡与剪辑 | 服务由用户在系统设置中开启 | 6s |
| 06 | 若悬浮窗尚未授权：设置 → 应用 → 魔法手势，开启「显示在其他应用上层」 | 卡片 1「允许显示在其他应用的上层」 | 悬浮窗权限同样在系统设置中开启 | 5s（已完成则可剪掉等待段） |
| 07 | 回到首页点击「✦ 启动手势控制」 | 按钮变为「✓ 手势控制运行中」，App 自动返回桌面；通知「魔法手势」出现并带「停止」按钮；系统摄像头指示点亮；右上角悬浮状态点出现 | 启动后通知常驻、摄像头指示可见，可随时一键停止 | 8s |
| 08 | 在另一个中性 App（空白网页 / 文件管理器）中，先移动光标，再做一次指尖轻点 | 悬浮光标跟随手指移动，轻点后出现点击反馈 | 识别在设备本机完成，画面不上传 | 8s |
| 09 | 回到 App 点击「停止所有控制」 | 状态「● 已请求停止，摄像头与悬浮控件即将关闭」；随后通知消失、悬浮点消失 | 停止后摄像头与悬浮控件立即关闭 | 6s |
| 10（可选加分） | 首页滚到最底部，展示「隐私政策与权限说明」文字链接，进入离线正文滚动几屏 | App 内离线隐私政策正文 | 隐私政策随 App 打包，无网络也能查看 | 5s |

## 2. 剪辑红线

- **不得剪掉**：披露弹窗正文、「暂不开启」拒绝路径、系统授权页面、跨 App 的实际操作过程、停止后的收尾。
- 可以只删：纯黑屏、等待加载、误触产生的多余画面（但误触本身若已被录进去，宁可整段重录）。
- 字幕与旁白必须和最终版本行为一致；**不要写「百分百准确」「精确距离」等 §6 禁止的表述**。
- 不要添加背景中的第三方素材、贴纸、音效素材（版权风险）。

## 3. 交付检查表

- [ ] 完整包含镜号 01–09，无可跳跃理解的缺失段
- [ ] 全程无脸、无自拍照片、无相册内容、无聊天与账号信息
- [ ] 桌面与最近任务画面干净，通知角标已清零
- [ ] 未出现短视频、社交、聊天类 App 界面
- [ ] 摄像头系统指示、前台通知、悬浮状态点三处可见性证据齐全
- [ ] 停止流程完整，停后无任何残留悬浮控件与通知
- [ ] 字幕无夸大表述
- [ ] 原始长视频与成片同时归档，方便审核追问时复核

## 4. 输出格式

- MP4 / H.264，1080p，帧率 30fps 即可。
- 各市场对审核视频的大小、时长限制不同（Google Play 促销视频为 YouTube 链接形式，国内多数市场直接上传文件），上传前以各家后台当页提示为准。
